# Stage 1 — tools, move the models, generate

## 1.1 Tools (run first, exactly)

```bash
go install webtyp.com/devflow/cmd/gotest@latest
go install webtyp.com/lang/cmd/langc@latest
go install webtyp.com/definitionc/cmd/definitionc@v0.1.42
export PATH="$PATH:$(go env GOPATH)/bin"
go get webtyp.com/model@v0.2.20 webtyp.com/crud@v0.0.12 webtyp.com/orm@v0.12.33 webtyp.com/storage@v0.2.2 webtyp.com/ddl@v0.0.50 webtyp.com/router@v0.4.22 webtyp.com/definitionc@v0.1.42 webtyp.com/view@v0.6.74
go mod tidy
```
`definitionc` is installed in `$(go env GOPATH)/bin`, which is NOT in the PATH of a fresh shell: put the `export PATH=…` in the SAME command as `definitionc`. `GOPRIVATE=webtyp.com/*,github.com/veltylabs/*`, `GOFLAGS=-mod=mod`; no `replace` in `go.mod`. **`definitionc` rewrites `go.mod` to older versions every run: after EVERY run repeat the `go get` line and `go mod tidy`.** The nested module `tests/` has its own `go.mod`: run the `go get` line there too (`cd tests && go get … && go mod tidy`). If a module cannot be fetched, stop and say so in the PR; never invent a hash.

Facts you need (asked before; do not ask again):

- Arguments: `crud.CreateArgs{Records []model.Model}`, `crud.UpdateArgs{IDs []string, Fields []string, Record model.Model}`, `crud.DeleteArgs{IDs []string}`, `crud.ReadArgs{ID, Search, After string, Limit int64, Filter model.Model}`; never a bare entity pointer, a `*List` or a map. Kinds are flat (`model.Pointer`/`List`/`Map` do not exist).
- Inside a rule `tx` is `crud.Tx`: `ReadOne(&rec, id)`, `ReadAll(newRow, crud.Query{Conditions, Order, After, Limit}, onRow)`, `Create`, `UpdateFields(&rec, id, cols)`, `Delete(&rec, id)`. Conditions: `storage.Eq/Neq/Gt/Gte/Lt/Lte/In/Like` (AND only); the tenant is applied by the store: **never add a `tenant_id` condition**; at most `crud.MaxPage` rows per read.
- **Update rules:** `crud` writes `next` after the rule with exactly the columns in `Fields`. A column the rule derives and the caller did not send is written by the rule with `tx.UpdateFields(&row, id, cols)`; a sent column is rewritten by `crud` from `next`, so the rule assigns `next.X = computed` for it.
- **The `id` of a table:** `ValidateInput` always requires a Text primary key unless the field is `ServerOnly`. A table whose rows the server creates: `id` is `OmitEmpty: true, ServerOnly: true` and Create records OMIT it; never send a `ServerOnly` field.
- `NotNull` on an `Int` or `Bool` rejects the zero value: `is_active` (false) must not be `NotNull`.

## 1.2 Move the models (one pass)

1. Create `authority/definition.go` (package `authority`) and MOVE into it, unchanged, `UserModel`, `SessionModel`, `IdentityModel`, `LANIPModel`, `OAuthStateModel` and `LANIdentityModel` from the root `definition.go`; delete them there. The root `definition.go` keeps ONLY the form models (`LoginDataModel`, `RUTLoginDataModel`, `SetupDataModel`, `RegisterDataModel`, `ProfileDataModel`, `PasswordDataModel`) and is regenerated by `definitionc` (its package has no `Module`: it generates only types; if `definitionc` complains, run it only in `authority/` and `passkey/`, `clientassertion/` as they are today). Delete `RegisterLANArgsModel` and `LANUserArgsModel`.
2. In the root `user.go` delete: `const ModelName`, the `Op*` constants (`OpMe`, `OpListUsers`, `OpUpsertUser`, `OpDeleteUser`, `OpRegisterLAN`, `OpUnregisterLAN`, `OpGetLAN`) and `NewView`'s `Op*` use (Stage 3 moves `NewView`). Keep `ResourceLANIdentity`, the `Provider*` constants, `ProfileDTO`, the errors and `Path*`.
3. In `authority/definition.go` edit the moved models exactly:
   - `UserModel`: `Allow: model.Create | model.Read | model.Update | model.Delete`; `Rules: model.Rules{Create: model.AddMyBusinessRule, Read: model.AddMyBusinessRule, Update: model.AddMyBusinessRule, Delete: model.AddMyBusinessRule}`; `id` → `{Name: "id", Type: model.Text(), DB: &model.FieldDB{PK: true}, OmitEmpty: true, ServerOnly: true}`; `status`, `avatar`, `created_at` get `ServerOnly: true` (the module writes them: `createUser` sets `active`, `updateUserAvatar`, `suspendUser`); `created_at` is `model.UnixTime()` and stays (crud stamps only `created_at`/`updated_at` of NANOSECOND columns: if `crud` refuses the mount with `ErrStampNotInt`, change `created_at` to `model.NanoTime()` and `CreatedAt: time.NowNano()` in the rule).
   - `SessionModel`, `IdentityModel`, `LANIPModel`, `OAuthStateModel`: no `Allow` (internal, written by the module); keep every field.
   - `LANIdentityModel`: `Allow: model.Create | model.Read | model.Delete`; `Rules: model.Rules{Create: model.HaveNoBusinessRule, Read: model.HaveNoBusinessRule, Delete: model.HaveNoBusinessRule}` (the RUT rules live in `RegisterLAN`); fields: `{Name: "user_id", Type: model.Text(), DB: &model.FieldDB{PK: true}}`, `{Name: "rut", Type: model.Text(), NotNull: true}`. It has `DB:` marks but NO table: its store is `lanStore` (Stage 2); do NOT add it to `Migrate`.
4. Add at the end of `authority/definition.go`:

```go
// Definition declara el módulo: usuarios y identidades LAN por crud; sesiones, identidades, IP de LAN y estado OAuth son internas.
var Definition = model.ModuleDefinition{
	Name: "user", // el prefijo wire y RBAC de siempre
	Entities: []model.Definition{UserModel, LANIdentityModel, SessionModel, IdentityModel, LANIPModel, OAuthStateModel},
}
```
   (An entity without `Allow` listed in `Entities` is declared but not mounted; if `definitionc` refuses that, list only `UserModel` and `LANIdentityModel`.)
5. Delete the hand-written `func (m *Module) ModelName() string` (`authority/mount.go`): `definitionc` writes it.
