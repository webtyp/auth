# Plan — `auth`: `Row:` marks become `Item:` marks

## Why

`webtyp.com/model` v0.2.8 replaces `model.Row`/`model.RowOf` (a runtime walk that `view` re-ran O(N²) times per
list) with ONE type, `model.Item{ID, Label, Description, Badge}`, and a field mark that names its slot
(`Item: model.ItemLabel` / `ItemDescription` / `ItemBadge`). `ormc` v0.1.26 generates a typed `func (m *X) Item()
model.Item` from those marks, and `webtyp.com/view` v0.6.48 lists only records that have it (`view.Record`),
computing each item once. `view.Item` is gone: everything speaks `model.Item`. Breaking change, no compatibility layer.

## Tools

```
go install webtyp.com/devflow/cmd/gotest@latest
go install webtyp.com/ormc/cmd/ormc@v0.1.26
go get webtyp.com/model@v0.2.8
go get webtyp.com/view@v0.6.48
```

`ormc@v0.1.26` rejects a field still written `Row: …` («Field.Row was replaced by Field.Item»): that error means a
mark was missed in Stage 1.

## Ecosystem search / Design gate

Reuses `model.Item`, `model.ItemLabel/ItemDescription/ItemBadge` (model v0.2.8) and the `Item()` that `ormc`
generates; no new exported name here. Deletes every `Row:` mark and every `model.RowOf` call (see the
`webtyp/model` v0.2.8 README for the full gate).

## Stage 1 — rename the marks (`model.go`), then regenerate

In every `model.Definition`: `Row: model.RowTitle` → `Item: model.ItemLabel`; `Row: model.RowDetail` →
`Item: model.ItemDescription`; `Row: model.RowBadge` → `Item: model.ItemBadge`. Then `go mod tidy` and `ormc`: each
listed model gets a generated `func (m *X) Item() model.Item` in `model_orm.go`.
Check: `grep -rn "Row: model\." --include=*.go .` → empty; `grep -c "Item() model.Item" model_orm.go` ≥ 1.

## Stage 2 — code and tests

- Every `model.RowOf(&x)` (tests included) → `x.Item()`; `.Title` → `.Label`; `.Detail` → `.Description`.
- Every `view.Item` → `model.Item`.
- Hand-written test doubles used as listed records implement `Item() model.Item` themselves.
Check: `grep -rn "RowOf\|model.Row\b\|view.Item\b" --include=*.go .` → empty.

## Stage 3 — test that the generated item is right

`tests/`: the existing `TestRowsDeclaredOnFields` (or equivalent) is renamed `TestItemsDeclaredOnFields` and asserts
`rec.Item()` per listed model (`ID`, `Label`, `Description`, `Badge`). A date badge is seconds since 1970.

## Stage 4 — docs

`README.md`/`docs/*`: the item is declared with `Item:` marks and generated by `ormc`.

## Delivery

- `gotest` green (also `-tags browser` tests). A PR that does not compile, or whose tests could not run, is a failed
  delivery. Environment: `GOPRIVATE=webtyp.com/*,github.com/veltylabs/*`, `GOFLAGS=-mod=mod`, `go mod tidy` before `ormc`.
- Never edit a generated file (`model_orm.go`) by hand: regenerate with `ormc`.
- Never pause to ask permission or report progress: when the check passes, commit, push and open the PR. Stuck 30
  minutes → open the PR listing what fails. Commit after every stage; never `git reset`, `git restore`,
  `git checkout -- <file>` or `git stash` on your own work.
